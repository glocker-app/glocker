Generate a random master key (MK) at registration — all data encrypted
under it (high entropy).

Wrap MK with a key derived from a passphrase (Argon2id(passphrase,
salt) → KEK; encrypt MK with KEK). Store the wrapped MK on the server
— useless without the passphrase.

On any device: type passphrase → derive KEK → fetch wrapped MK →
unwrap → MK in memory → decrypt. Portable, and the server never sees
MK or passphrase.

The agent stores MK in a root-only file locally (so it encrypts
without prompting every sync).

Add a printable recovery code = a second wrapping of MK under a random
code, so "forgot passphrase" ≠ instant data death.

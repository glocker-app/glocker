glocker — site design variants

Three takes on the same copy. Pick one and I’ll carry it through the rest of the site and the glockpeek dashboard.

1 — Journal Ruled paper, one ink colour, diagonal hatching where a fill would go. Headings and marginalia in a pen hand; the install commands are a printed slip taped to the page. 2 — Status terminal The whole page drawn as one glocker -status frame, using that command’s exact palette: amber heads, dim box rules, green and red only where they mean something. Scanlines and an amber bloom on a near-black screen. 3 — Modern dashboard Low contrast, hairline dividers instead of cards, one desaturated slate accent. The hero is a week of blocking windows read as a schedule. Follows the reader’s light or dark setting.
Files live in website/variants/. The current site is website/index.html, untouched.
